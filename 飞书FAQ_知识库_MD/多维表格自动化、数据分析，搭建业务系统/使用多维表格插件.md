# 使用多维表格插件

原文链接：https://www.feishu.cn/hc/zh-CN/articles/948392023042

## 正文

一、功能简介​

插件是多维表格推出的灵活、便捷的开放能力。有编程能力的用户可编写代码来实现自定义功能，无编程能力的用户也可以使用插件市场的各类型插件，实现不同的业务诉求。​

注：未开启高级权限时，拥有可编辑或可管理权限的用户可以添加插件。开启高级权限时，仅拥有可管理权限的用户可以添加插件。​

常见插件介绍：​

  * 查找替换插件：根据自定义逻辑批量查找和替换多维表格中的数据。​



  * “导出 Excel：内嵌图片”插件：将多维表格导出为 Excel 时，可以把附件中的图片直接嵌入 Excel 单元格中。​



  * Excel 对比导入插件：将本地 Excel 文件轻松导入到已有的多维表格中，支持追加内容和对比导入。​



  * 删除重复记录插件：选择一个或多个字段作为识别条件，即可查找并删除重复记录。​



  * 多数据表合并插件：将多个数据表的数据合并到一个指定的数据表中。​



  * 网页预览插件：点击含有网页链接的单元格，即可预览对应的网页内容。​



  * 字段翻译插件：将多维表格的文本字段作为输入，翻译为指定语言后输出到另一个文本列。​



  * 二维码/条形码生成器插件：将 URL 或文本轻松转化为二维码或条形码，并自动上传到多维表格作为附件。​



  * 文本拆分多列插件：将文本字段拆分成多个字段，支持多种分隔符。​



  * 随机抽取数据插件：在文本、人员、创建人、单选或公式类型的字段中，随机抽取数据。适用于抽奖、人员抽选、号码分配、随机抽取工单进行质检等情景。支持设置抽取数量，并将抽取的结果记录在表中。​



二、操作流程​

打开多维表格，点击右上角的 多维表格插件 图标。右侧弹出的面板会展示 为你推荐 的一些插件，你也可以点击下方的 探索插件市场 按钮来搜索和使用更多插件。​

当前多维表格提供了许多优秀的插件，下面以 查找替换 插件为例进行说明。​

  1. 点击右上角的 多维表格插件 按钮 > 探索插件市场，搜索 查找替换 插件。鼠标悬停在插件上，点击 使用 按钮即可进行设置。​



  2. 配置以下选项：​



查找模式：支持简易、正则表达式和 JSON 字典模式。​

数据表和字段：选择要查找的数据范围。​

查找和替换的内容：根据所选择查找模式的要求，输入要查找和替换的内容。​

  3. 点击 查找 按钮，下方将按字段展示查找结果。​



  4. 按需选择替换单个值或全部替换。​
