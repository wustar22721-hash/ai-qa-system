一、功能简介​

多维表格的字段相当于表格的“列”，在多维表格中可以设置不同的字段类型，以保证每列填写内容的格式规范。目前，多维表格提供 3 大类字段，满足多样信息需求。​

注：多维表格首列为索引列，不能被删除、移动或隐藏。​

​

​| 字段类型​| 说明​  
---|---|---  
​​​​​​常规​​| [文本](https://www.feishu.cn/hc/zh-CN/articles/942865849478)​| 输入较长的文本内容，支持表情等各种特殊符号，在单元格内可以通过按下 Shift + Enter 或 CTRL + Enter （Windows）或 Command + Enter （Mac）换行。​  
​| [单选](https://www.feishu.cn/hc/zh-CN/articles/624094577996)​| 用于给记录打标签，可以自定义颜色和选项内容，在单元格内只能选择一个选项。​  
​| [多选](https://www.feishu.cn/hc/zh-CN/articles/624094577996)​| 用于给记录打标签，可以自定义颜色和选项内容，在单元格内可以选择多个选项。​  
​| [人员](https://www.feishu.cn/hc/zh-CN/articles/588912197499)​| 可以填入内部成员或外部联系人，可以同时添加多个人员。​  
​| [群](https://www.feishu.cn/hc/zh-CN/articles/810974523500)[组](https://www.feishu.cn/hc/zh-CN/articles/810974523500)​| 可填入内部或外部群组。​  
​| [日期](https://www.feishu.cn/hc/zh-CN/articles/360049067920)​| 支持以多种格式显示日期与时间。​  
​| [附件](https://www.feishu.cn/hc/zh-CN/articles/532389628624)​| 支持上传多种文件类型的附件。​  
​| [数字](https://www.feishu.cn/hc/zh-CN/articles/909323330538)​| 支持通过小数、百分比等形式展示数字。​  
​| [复选框](https://www.feishu.cn/hc/zh-CN/articles/329254347776)​| 可勾选的小方块，可快速标记记录为“完成”状态。​  
​| [超链接](https://www.feishu.cn/hc/zh-CN/articles/695334779573)​| 输入网页地址，可以自定义网址的文本名称。​  
​| [公式](https://www.feishu.cn/hc/zh-CN/articles/360049067853)​| 可以通过丰富的函数公式对字段进行计算。​  
​| [查找引用](https://www.feishu.cn/hc/zh-CN/articles/398396737655)​| 基于 FILTER 函数的字段，可以快捷查找统计数据。​  
​​​​​​业务​​| [流](https://www.feishu.cn/hc/zh-CN/articles/127551385673)[程](https://www.feishu.cn/hc/zh-CN/articles/127551385673)​| 可自定义流程节点名称、展示事件当前状态。​  
​| [按](https://www.feishu.cn/hc/zh-CN/articles/339066898695)[钮](https://www.feishu.cn/hc/zh-CN/articles/339066898695)​| 自动化流程的触发条件，点击按钮可触发自动化操作。​  
​| [自动编号](https://www.feishu.cn/hc/zh-CN/articles/158710285916)​| 为每一条记录生成唯一可识别且自动递增的编号。​  
​| [电话号码](https://www.feishu.cn/hc/zh-CN/articles/209370117035)​| 录入并管理联系人的电话号码，在移动端可便捷拨打电话或发送短信。​  
​| [Emai](https://www.feishu.cn/hc/zh-CN/articles/396147301828)[l](https://www.feishu.cn/hc/zh-CN/articles/396147301828)​| 录入人员的邮箱地址，可校验邮箱格式并便捷发送邮件。​  
​| [地理位置](https://www.feishu.cn/hc/zh-CN/articles/603868481939)​| 快速记录位置信息或获取实时地理位置。​  
​| [条码](https://www.feishu.cn/hc/zh-CN/articles/193772731228)​| 通过移动端自动扫描并识别条形码、二维码中的信息。​  
​| [进度](https://www.feishu.cn/hc/zh-CN/articles/422425843868)​| 通过进度条视觉化直观展示项目进程。​  
​| [货币](https://www.feishu.cn/hc/zh-CN/articles/705915388398)​| 根据不同市场或数据使用对象，选择相应的货币。​  
​| [评](https://www.feishu.cn/hc/zh-CN/articles/788252329598)[分](https://www.feishu.cn/hc/zh-CN/articles/788252329598)​| 用于评价、调研等场景，可自定义评分范围及图形。​  
​​​高级​​| [双向关联](https://www.feishu.cn/hc/zh-CN/articles/653027931590)​| 对两个数据表中的数据进行双向关联。​  
​| [单向关联](https://www.feishu.cn/hc/zh-CN/articles/361914682520)​| 对两个数据表中的数据进行单向关联。​  
​| 创建人​| 每一条记录的创建者，由系统自动生成。​  
​| 修改人​| 每一条记录的最后修改人，由系统自动生成。​  
​| 创建时间​| 每一条记录的创建时间，由系统自动生成。​  
​| 最后更新时间​| 每一条记录最后一次被修改的时间，由系统自动生成。​

二、操作流程​

新建字段​

你可以通过以下方式新增字段：​

方式 1：在表格视图中，点击最后一个字段右侧的 + 即可新增一个字段。​

通过方式 1、2、3 新建字段时，你可以选择多维表格智能生成的推荐字段。​

推荐字段是由 AI 参考当前多维表格名称、当前数据表名称、当前数据表中已有的字段名称和字段类型给出的。 你可以点击选择合适的推荐字段，按需进行修改调整，最后点击 确认 即可。每次重新新建字段时，会刷新给出新的推荐字段。​

注：推荐字段仅在桌面端可见。​

  * 将鼠标悬停在冻结线上，左右拖拽即可调整冻结范围。​
