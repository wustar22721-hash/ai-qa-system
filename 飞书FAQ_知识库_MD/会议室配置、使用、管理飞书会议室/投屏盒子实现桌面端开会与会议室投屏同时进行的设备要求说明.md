# 投屏盒子实现桌面端开会与会议室投屏同时进行的设备要求说明

原文链接：https://www.feishu.cn/hc/zh-CN/articles/337194024096

## 正文

一、简介​

在使用飞书投屏盒子的过程中，若想实现在桌面端加入视频会议和会议室投屏同时进行，需满足文中的设备要求。​

二、信息参考​

本地会议室启用流畅模式 ​

在本地会议室投屏时，若勾选 流畅模式，投屏画面将支持 1080p @ 30fps。需满足下列设备配置要求：​

​

设备​| CPU 型号​| 内存​  
---|---|---  
Mac​| Mac Intel(R) Core(TM) i5-7360U​| 8G 及以上 ​  
Windows ​| Intel(R) Core(TM) i5-10210U ​| 16G 及以上 ​  
  
​

本地会议室启用超清模式 ​

在本地会议室投屏时，若不勾选 流畅模式，投屏画面将支持超清画质（ Mac 投屏 2k@30fps， Windows 投屏 2k@15fps）。 需满足下列设备配置要求：​

​

设备​| CPU 型号​| 内存​  
---|---|---  
Mac​| Mac Intel(R) Core(TM) i5-1038N ​| 16G 及以上 ​  
Windows ​| Intel(R) Core(TM) i5-10210U ​| 16G 及以上 ​  
  
​

无线超清 4K 投屏分辨率需满足条件​

开启 4K 的情况下：投屏文档，最高支持 4K@10fps；投屏视频内容，最高支持2K@30fps。需满足下列条件：​

  * 投屏 PC 设备显示器分辨率支持 4K​



  * 企业已经申请投屏盒子配置 4K​



  * 进行投屏的飞书客户端与投屏盒子所处同一网段​



如何查看设备配置 ​

  * Mac ​



在界面上方的菜单栏点击 苹果 图标 > 关于本机 > 更多信息 > 系统报告，查看处理器速度，核总数和内存。 ​

  * Windows ​



方法 1：点击菜单栏中的 搜索 图标，在搜索栏中输入 任务管理器。点击 性能 标签，找到 CPU 项，查看基准速度、内核、逻辑处理器等信息。​

方法 2：通过第三方工具（如 CPU-Z）可以看到设备 CPU 的核心数和线程数。 ​
