# 管理员进行字段管理

原文链接：https://www.feishu.cn/hc/zh-CN/articles/973209819304

## 正文

一、功能简介​

​

🔖

内测信息：文内包含部分内测功能。​

谁能操作：超级管理员或拥有字段管理权限的管理员。​

​

成员字段包括预置字段和自定义字段。预置字段为系统内置字段，无需管理员添加和设置；自定义字段可以由管理员根据实际需求添加。​

设置成员字段后，还可在名片页、会话窗口、通讯录列表中灵活展示字段信息。​

二、操作流程​

配置成员预置字段信息​

预置字段包括基础信息、工作信息、个人信息、银行卡信息、证件信息、合同信息等。管理员可以在人事管理模式中批量添加或修改成员预置字段信息。​

  1. 进入[飞书管理后台](https://feishu.cn/admin)，点击 组织架构 > 成员与部门 > 人事管理模式。​



  2. 点击 导出 > 自定义导出。​

配置自定义字段​

管理员可为成员和部门添加自定义字段，拓展成员和部门的信息。​

添加自定义字段​

  1. 进入[飞书管理后台](https://feishu.cn/admin)，点击 组织架构 > 字段管理。​

配置成员自定义字段信息​

管理员可以通过以下 3 种方式为成员配置自定义字段信息：​

方法 1：为单个成员配置​

  1. 进入[飞书管理后台](https://feishu.cn/admin)，点击 组织架构 > 成员与部门。​



  2. 在 成员 标签页中点击具体成员右侧的 详情。​



  3. 在 自定义信息 页点击 编辑自定义信息，填写成员自定义字段信息。​



  4. 点击 保存，完成设置。​



​

方法 2：批量导出/导入​

进入[飞书管理后台](https://feishu.cn/admin)，在 组织架构 > 成员与部门 > 成员 中通过 批量导入/导出 功能进行操作。具体信息请参考[管理员修改成员信息](https://www.feishu.cn/hc/zh-CN/articles/360043261194-%E7%AE%A1%E7%90%86%E5%91%98%E4%BF%AE%E6%94%B9%E6%88%90%E5%91%98%E4%BF%A1%E6%81%AF)。​

方法 3：Open API 导入​

管理员可以使用[开放平台 API 接口](https://open.feishu.cn/document/server-docs/contact-v3/resources#3b13f0a0)批量写入多个成员信息。​

配置部门自定义字段信息​

方法 1：新建部门时配置​

  1. 进入[飞书管理后台](https://feishu.cn/admin)，点击 组织架构 > 成员与部门。​



  2. 在 部门 标签页中点击 新建部门。​



  3. 在[新建部门](https://www.feishu.cn/hc/zh-CN/articles/360033588234-%E7%AE%A1%E7%90%86%E5%91%98%E5%88%9B%E5%BB%BA%E9%83%A8%E9%97%A8%E5%8F%8A%E9%83%A8%E9%97%A8%E7%BE%A4)的弹窗中点击 \+ 填写更多信息。​



  4. 在 自定义信息 模块中填写部门自定义字段信息。​



  5. 填写完成后点击 确定。​

API 调用设置​

管理员可以使用[开放平台 API 接口](https://open.feishu.cn/document/server-docs/contact-v3/custom_attr/overview)更新自定义字段。操作时，可以通过字段 ID 来获取需要更新的自定义字段。​

  1. 进入[飞书管理后台](https://feishu.cn/admin)，点击 组织架构 > 字段管理。​



  2. 在 字段列表 页面右上方点击 API 调用设置。​



  3. 在弹窗中开启 允许开放平台通讯录 API 调用，点击 确定。​
