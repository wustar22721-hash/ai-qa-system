# 使用邮箱快捷键

原文链接：https://www.feishu.cn/hc/zh-CN/articles/961507807785

## 正文

一、功能简介​

你可以在桌面端使用飞书邮箱快捷键，高效处理邮件。​

二、快捷键一览​

​

使用场景​| 操作​| Windows​| Mac​| 说明​  
---|---|---|---|---  
邮箱全局​​| 打开搜索​​| Ctrl + F ​​|  ⌘ + F ​| 若未打开读信页，使用快捷键后将打开飞书全局搜索​若已打开读信页，使用快捷键后将打开邮件页内搜索​  
​| 关闭活动窗口​| Esc ​|  ⌘ + W 或 Esc ​| 关闭活动窗口​  
​| 新建邮件​| Ctrl + N ​|  ⌘ + N ​| 创建一封新草稿，并打开写信窗口​  
文件夹/标签列表​​| 切换文件夹/标签​​|  ↑ ​|  ↑ ​| 切换到上一个文件夹或标签​  
​| ​|  ↓ ​|  ↓ ​| 切换到下一个文件夹或标签​  
邮件列表​​| 切换邮件​​|  ↑ ​|  ↑ ​| 切换到上一封邮件​  
​| ​|  ↓ ​|  ↓ ​| 切换到下一封邮件​  
​| 多选邮件​​| Shift + ↑ ​| Shift + ↑ ​| 选中当前邮件和上一封邮件​  
​| ​| Shift + ↓ ​| Shift + ↓ ​| 选中当前邮件和下一封邮件​  
​| 全选邮件​| Ctrl + A ​|  ⌘ + A ​| 全选邮件​  
​| 标为已读​| Ctrl + Q ​|  ⌘ + T ​| /​  
​| 标为未读​| Ctrl + U ​|  ⌘ + Shift + T ​| /​  
​| 全标已读​| Ctrl + Shift+ Q ​|  ⌘ + Option + T ​| 将文件夹/标签内的邮件全标已读​  
​| 删除邮件​​| Delete​| Delete​​| 选中邮件后，使用快捷键，删除选中的邮件，支持多选​​  
​| 永久删除邮件​​| Delete​​|  Delete​​| 在“已删除”文件夹选中邮件后，使用快捷键，永久删除选中的邮件，支持多选​​  
​| 归档邮件​| Ctrl + E ​|  ⌘ + E ​| 选中邮件后，使用快捷键，归档选中的邮件​  
​| 移至文件夹​| Ctrl + Shift + M ​|  ⌘ + Shift + M ​| 打开“移至文件夹”菜单​​  
​| 选择标签​| Ctrl + Shift + L ​|  ⌘ + Shift + L ​| 打开“选择标签”菜单​​  
读信页​​​| 邮件内搜索切换位置​​| Enter​| Enter​| 进入页内搜索后，跳转至下一个包含关键词的部分​  
​| ​| Shift + Enter​| Shift + Enter​| 进入页内搜索后，跳转至上一个包含关键词的部分​  
​| 回复​| Ctrl + R ​|  ⌘ + R ​| 回复邮件（仅发件人），若会话中有多封，则是回复最新的一封​  
​| 回复全部​| Ctrl + Alt + R ​|  ⌘ + Option + R ​| 回复全部（包括发件人、抄送人和其他收件人），若会话中有多封，则是回复最新的一封​  
​| 转发​| Ctrl + J ​|  ⌘ + J ​| 转发邮件，若会话中有多封，则是转发最新的一封​  
​| 打印邮件​| Ctrl + P ​|  ⌘ + P ​| 打开读信页后，使用快捷键进入邮件打印​  
写信页全局​​| 移动焦点​| Tab​| Tab ​| 移动焦点到下一个位置​  
​| 回退焦点​| Shift + Tab​| Shift + Tab​| 焦点回退到上个位置，支持从编辑器回到主题输入框​  
​| 发送邮件​| Ctrl + Shift + Enter​|  ⌘ + Shift + Enter​| 等同于点击“发送”按钮​​  
​| 关闭写信窗口​| Esc​|  ⌘ + W 或 Esc ​| /​  
​| 保存草稿​| Ctrl + S ​|  ⌘ + S ​| /​  
编辑正文​​| 撤销​| Ctrl + Z ​|  ⌘ + Z ​| 撤销上一步操作​  
​| 重做​| Ctrl + Shift + Z ​|  ⌘ + Shift + Z ​| 重做上一步操作​  
​| 增大字号​| Ctrl + + ​|  ⌘ + + ​| 选中文字后，使用快捷键，字号增大，最大到 50 号​  
​| 减小字号​| Ctrl + - ​|  ⌘ + - ​| 选中文字后，使用快捷键，字号减小，最小到 10 号​  
​| 粗体​| Ctrl + B ​|  ⌘ + B ​| /​  
​| 斜体​| Ctrl + I ​|  ⌘ + I ​| /​  
​| 下划线​| Ctrl + U ​|  ⌘ + U ​| /​  
​| 删除线​| Ctrl + Shift + X ​|  ⌘ + Shift + X ​| /​  
​| 左对齐​| Ctrl + Shift + { ​​|  ⌘ + Shift + { ​​| 选中内容后，使用快捷键，所有选中行左对齐；​光标停留在行内，使用快捷键，该行内容左对齐​  
​| 右对齐​| Ctrl + Shift + } ​|  ⌘ + Shift + } ​​| 选中内容后，使用快捷键，所有选中行右对齐；​光标停留在行内，使用快捷键，该行内容右对齐​  
​| 增加缩进​​| Ctrl + ] ​​|  ⌘ + ] ​| 选中内容后，使用快捷键，所有选中行增加一级缩进；​光标停留在行内，使用快捷键，该行增加一级缩进​  
​| 减少缩进​​| Ctrl + [ ​|  ⌘ + [ ​​| 选中内容后，使用快捷键，所有选中行减少一级缩进；​光标停留在行内，使用快捷键，该行减少一级缩进​  
​| 有序列表​| Ctrl + Shift + 7 ​|  ⌘ + Shift + 7 ​​| 选中内容后，使用快捷键，所有选中行变为有序列表；​光标停留在行内，使用快捷键，该行变为有序列表​  
​| 无序列表​| Ctrl + Shift + 8 ​|  ⌘ + Shift + 8 ​​| 选中内容后，使用快捷键，所有选中行变为无序列表；​光标停留在行内，使用快捷键，该行变为无序列表​  
​| 引用​| Ctrl + Shift + > ​|  ⌘ + Shift + > ​​| 选中内容后，使用快捷键，所有选中行应用引用样式；​光标停留在行内，使用快捷键，该行应用引用样式​  
​| 超链接​| Ctrl + K ​|  ⌘ + K ​​| 选中内容后，使用快捷键，设置选中内容的超链接；​光标停留在行内，使用快捷键，插入超链接​
