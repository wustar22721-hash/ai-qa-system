# 使用幻灯片快捷键

原文链接：https://www.feishu.cn/hc/zh-CN/articles/058251273274

## 正文

一、功能简介​

在创建、编辑和演示幻灯片的过程中，你可以使用键盘快捷键，在幻灯片中进行各种快速操作，如查找替换、复制粘贴、字体加粗、快速演示，提高工作效率。​

二、操作流程​

  1. 打开快捷键列表​



你可以通过以下任一方式，在幻灯片文件中打开快捷键列表，查找自己所需的快捷键：​

  * 在键盘上按 Ctrl + /（Windows 操作系统）或 ⌘ + /（Mac 操作系统）按钮。​



  * 鼠标悬停在幻灯片右下角的 ？上；在弹出的菜单中点击 效率指南。 ​



  2. 使用快捷键​



2.1 通用快捷键​

在幻灯片创建和编辑过程中，你可以使用以下常用的快捷方式。​

​

操作​| Windows 操作系统​| Mac 操作系统​  
---|---|---  
查找​| Ctrl + F​| ⌘ + F​  
查找和替换​| Ctrl + Shift + F​| ⌘ + Shift + H​  
评论​注：评论选中的幻灯片页面​| Ctrl + Alt + M​| ⌘ + Option + M​  
撤销​| Ctrl + Z​| ⌘ + Z​  
重做​注：撤销上一个撤销操作​| Ctrl + Shift + Z​​| ⌘ + Shift + Z​  
复制​| Ctrl + C​| ⌘ + C​  
拷贝​注：生成所选页面对象/左侧目录中页面的复制品。​| Ctrl + D​| ⌘ + D​  
剪切​| Ctrl + X​| ⌘ + X​  
粘贴​| Ctrl + V​| ⌘ + V​  
全选​| Ctrl + A​| ⌘ + A​  
删除​| Delete​| Delete​  
上移一层​| Ctrl + ↑​| ⌘ + ↑​  
下移一层​| Ctrl + ↓​| ⌘ + ↓​  
置于顶层​| Ctrl + Shift + ↑​| ⌘ + Shift + ↑​  
置于底层​| Ctrl + Shift + ↓​| ⌘ + Shift + ↓​  
左对齐​| Alt + A​| Option + A​  
水平居中​| Alt + H​| Option + H​  
右对齐​| Alt + D​| Option + D​  
顶端对齐​| Alt + W​| Option + W​  
垂直居中​| Alt + V​| Option + V​  
底端对齐​| Alt + S​| Option + S​  
垂直分布​注：选中 3 个或以上对象，使对象垂直分布。​| Ctrl + Alt + V​| ⌘ + Option + V​  
水平分布​注：选中 3 个或以上对象，使对象水平分布。​| Ctrl + Alt + H​| ⌘ + Option + H​  
新建幻灯片​注：需要先在左侧目录选中想添加幻灯片的位置。​| Ctrl + M 或 Enter​| Ctrl + M 或 Enter​​  
快速复制​注：快速生成所选页面对象/左侧目录中页面的复制品。​| Alt + 鼠标拖动​| Option + 鼠标拖动​  
选中多个对象​注：选中单个页面中多个对象或选中左侧目录中多个页面。​| Shift/Ctrl + 鼠标点击​| Shift/⌘ + 鼠标点击​  
锁定纵横比​注：按照原本的纵横比例，对选中的对象进行等比例缩放。​| Shift + 鼠标拖拽缩放​​| Shift + 鼠标拖拽缩放​  
中心放缩​注：以选定对象的中心点作为原点进行缩放操作。​| Alt + 鼠标缩放​| Option + 鼠标缩放​  
退出文本编辑​| Esc​| Esc​  
  
​

2.2 演示快捷键​

在幻灯片演示模式下，你可以使用以下快捷键。​

​

操作​| Windows 操作系统​| Mac 操作系统​  
---|---|---  
当前演示​| Ctrl + Enter​| ⌘ + Enter​  
从头开始演示​| Ctrl + Shift + Enter​| ⌘ + Shift + Enter​  
上一页​| ↑ 或 ←​| ↑ 或 ←​  
下一页​| 空格 或 ↓ 或 →​| 空格 或 ↓ 或 →​  
退出演示模式​| Esc​| Esc​  
  
​

2.3 文字快捷键​

编辑文本格式时，你可以使用以下快捷键。​

​

操作​| Windows 操作系统​| Mac 操作系统​  
---|---|---  
加粗​| Ctrl + B​| ⌘ + B​  
斜体​| Ctrl + I​| ⌘ + I​  
下划线​| Ctrl + U​| ⌘ + U​  
删除线​| Ctrl + Shift + X​| ⌘ + Shift + X​  
缩进​| Tab​| Tab​  
取消缩进​| Shift + Tab​| Shift + Tab​  
有序列表​| 1.+ 空格​| 1.+ 空格​  
无序列表​| *+空格​| *+空格​  
  
​

2.4 组合快捷键​

组合不同对象时，你可以使用以下快捷键。​

​

操作​| Windows 操作系统​| Mac 操作系统​  
---|---|---  
组合​| Ctrl + G​| ⌘ + G​  
取消组合​| Ctrl + Shift + G​| ⌘ + Shift + G​  
  
​

2.5 移动快捷键​

移动对象位置时，你可以使用以下快捷键。​

​

操作​| 快捷键​  
---|---  
上移​| ↑ ​  
下移​| ↓​  
左移​| ←​  
右移​| →​  
垂直或水平移动对象​| Shift + 鼠标拖动​
