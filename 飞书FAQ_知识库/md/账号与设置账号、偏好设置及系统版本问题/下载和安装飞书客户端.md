飞书 Windows 客户端​

系统要求 ​

支持 Windows 7 及以上版本，提供 64 位和 32 位版本的 Windows 系统安装包。​

下载及安装 ​

  1. 点击访问[官网](http://feishu.cn/download)，将鼠标光标移至 Windows 客户端 卡片上。​



  2. 点击 立刻下载 下载 64 位安装包；点击 32 位版本 下载 32 位安装包。​



  3. 下载完成后，在资源管理器中打开下载文件夹。 ​



  4. 双击打开 Feishu-X-X-X.exe，按照指引完成安装。​



  5. 在桌面双击飞书图标或从开始菜单启动飞书，输入你的账号和密码并登录，即可开始使用。​



飞书 macOS 客户端​

系统要求 ​

支持 macOS 10.13 及以上版本。如果你正在使用 macOS 10.12 或更低版本，请参考[苹果升级说明 ](https://support.apple.com/zh-cn/HT201475)升级到最新版本的 macOS 系统。​

注： Apple 芯片版客户端支持 macOS 11.0 及以上版本。​

下载及安装 ​

  1. 点击访问[官网](http://feishu.cn/download)，点击  macOS 客户端。​



  2. 选择适合的客户端版本，你可以选择 下载 Intel 芯片版客户端 或 下载 Apple 芯片版客户端。​



注：你可以通过以下方式确认本机芯片类型​

  1. 点击屏幕左上角的 苹果 图标，点击 关于本机。​



  2. 在弹出窗口的“处理器”或“芯片”栏目可以查看本机的芯片类型。​



  3. 下载完成后，在访达中打开下载文件夹。 ​



  4. 双击打开 Feishu_X.X.X.dmg，拖动 飞书 图标到 Applications 文件夹。 ​



  5. 从启动台或应用文件夹启动飞书，输入你的账号和密码并登录，即可开始使用。​
