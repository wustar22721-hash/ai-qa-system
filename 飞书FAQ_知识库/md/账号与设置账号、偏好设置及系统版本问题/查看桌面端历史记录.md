# 查看桌面端历史记录

原文链接：https://www.feishu.cn/hc/zh-CN/articles/955968064674

## 正文

一、功能简介​

​

🔖

版本要求：飞书 V7.11 及以上版本​

​

通过历史记录功能，你可以快速查看在飞书桌面端内打开过的会话、文档、邮件、应用等页面。​

二、操作流程​

打开历史记录页面​

  * macOS 系统：使用飞书桌面端时，你可以点击系统状态栏上的 历史记录，查看最近打开过的会话、文档、邮件、应用等页面。​



​

  * Windows 系统：使用飞书桌面端时，你可以点击桌面端导航栏右上角的 历史记录，查看最近打开过的会话、文档、邮件、应用等页面。​



​

注：系统状态栏中最多可展示 20 个最近打开过的页面。​

如需查看所有历史记录，点击 查看全部历史记录，即可在桌面端内打开 历史记录 页面。​

​

![](https://p1-hera.feishucdn.com/tos-cn-i-jbbdkfciu3/ea5765ee4fd04c1d89c06a0feea1c205~tplv-jbbdkfciu3-image:0:0.image)​​

你也可使用快捷键直接打开 历史记录 页面：​

  * macOS 系统： ⌘ + Y。​



  * Windows 系统： Ctrl + H。​



管理历史记录​

你可对历史记录进行以下 3 个操作：​

  1. 查看历史记录详情：点击需要查看的单条记录，即可跳转至对应界面查看详情。​



​
