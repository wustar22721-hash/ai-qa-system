# 通过网页加入飞书视频会议

原文链接：https://www.feishu.cn/hc/zh-CN/articles/360049067679

## 正文

一、功能简介​

获取会议链接或会议 ID 后，参会人可通过网页快速加入飞书视频会议。 ​

​

🔖

说明：​

  * 网页版视频会议不包含发起录制、美颜等高级功能，也不支持成为会议主持人。如需完整会议体验，建议[下载飞书客户端](http://feishu.cn/download)。​



  * 支持通过桌面端、移动端网页加入视频会议。设备要求如下：​



  * 桌面端网页：​



  * 操作系统：支持 Windows、macOS、Linux Ubuntu (16+, X64) 系统。​



  * 浏览器：支持 Chrome 74+、360、Microsoft Edge、Safari 13+、Firefox 及 Opera（建议升级至最新版本）。​



  * 移动端网页：​



  * 操作系统：支持 Android、iOS、iPadOS 系统。​



  * 浏览器：支持 Chrome 74+、Safari 13+ 及微信浏览器（建议升级至最新版本）。​



​

二、操作流程​

加入会议​

获取会议链接、会议 ID 后，你可以通过以下两种方式加入视频会议。​

方式 1：通过会议链接加入​

  1. 获取会议链接后，在网页中打开该链接，点击 网页版入会。​



  * ​

  2. 输入框中将自动填充本场会议 ID，点击 加入 即可加入会议。​



方式 2：通过会议 ID 加入​

  1. 在网页中访问 [https://vc.feishu.cn](https://vc.feishu.cn)，点击 加入会议。 ​

  2. 输入 9 位数会议 ID，点击 加入 即可加入会议。 ​



注：​

  * 若会议开启了[等候室](https://www.feishu.cn/hc/zh-CN/articles/360049067677)，参会人需等待主持人核验身份并通过后方可入会。 ​



  * 首次通过网页加入飞书视频会议，需允许浏览器使用麦克风或摄像头，否则会议中将无法使用相关功能。 ​



  * 无飞书账号或未在浏览器登录飞书时，加入会议时需先注册或登录飞书账号，或以访客身份完成验证后入会。​



共享内容​

通过桌面端网页加入视频会议后，点击下方工具栏中的 共享 图标，在相应标签页下点击所需共享的内容，点击 分享，即可与参会人共享对应内容。如果开启了分享音频设置，还可同步共享音频。​

支持共享某个浏览器标签页（包括 Chrome、360、Microsoft Edge、Safari、Firefox 及 Opera 浏览器）、单个应用窗口（包括浏览器与 App 窗口）或整个桌面屏幕。​

另外，若其他参会人通过客户端视频会议[妙享](https://www.feishu.cn/hc/zh-CN/articles/360047005834)了文档，你通过桌面端网页加入视频会议后，可以跟随共享人浏览内容，也可以自由浏览。​

注：​

  * Windows 支持共享系统中、标签页中的音频，macOS 仅支持共享标签页中的音频。 ​



  * 通过移动端网页加入视频会议，仅可接收屏幕共享，无法发起共享及使用妙享功能。​



聊天与表情回应​

通过桌面端、移动端网页加入视频会议后，点击下方工具栏中的表情、聊天框等相关图标，可在会议中[发送表情或消息](https://www.feishu.cn/hc/zh-CN/articles/360047006054)。​

设置虚拟背景​

通过桌面端网页加入视频会议后，点击下方工具栏中 摄像头图标 右侧的 ^ 图标 > 特效，或点击 ··· 更多 图标 > 特效，即可设置虚拟背景。你可选择对人像之外的背景区域进行虚化，或选择系统自带的虚拟背景。​

注：通过移动端网页加入视频会议，不支持设置虚拟背景。​
