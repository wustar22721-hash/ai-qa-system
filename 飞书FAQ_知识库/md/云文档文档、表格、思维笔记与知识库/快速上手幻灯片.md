# 快速上手幻灯片

原文链接：https://www.feishu.cn/hc/zh-CN/articles/047096658995

## 正文

一、认识幻灯片​

​

🔖

版本要求：飞书 V7.0 及以上版本​

​

飞书幻灯片是飞书办公套件中的在线演示文稿，创作门槛低、支持多人协同编辑。​

通过飞书幻灯片，你可以：​

  * 快速创建文件：新建空白幻灯片、基于模板创建幻灯片（即演示文稿），或者导入已有的 .pptx 格式文件。​



  * 高效编辑内容：快速添加或删除幻灯片页面，调整页面顺序、背景或修改页面尺寸，适用不同应用场景。​



  * 插入丰富内容：自由添加文字、图形、图片、图表、表格、音视频、布局等不同的对象，还可以为不同的对象设置格式。​



  * 分享与协作：通过分享文件，可邀请其他成员发表评论、进行在线协作。​



  * 轻松演示内容：借助演讲者视图和备注功能，轻松演示生动内容。​



  * 灵活保存文件：将在线幻灯片文件下载为 PDF 文件（.pdf）或本地 PPT 文件（.pptx）文件，或者转换为在线模板。​

三、八步上手幻灯片​

步骤一、创建幻灯片​

你可以新建空白幻灯片或基于模板创建幻灯片，也可以导入已有的幻灯片。​

新建空白幻灯片或基于模板创建幻灯片​

在[云文档主页](https://www.feishu.cn/drive/home/)，点击 新建 > 幻灯片。​

​

250px|700px|reset

![](https://p1-hera.feishucdn.com/tos-cn-i-jbbdkfciu3/80e99fb2fa7245f5a38a2e5bf727b2ca~tplv-jbbdkfciu3-image:0:0.image)​​

你可以新建空白幻灯片，也可以直接使用已有模板。[幻灯片模板库](https://www.feishu.cn/drive/template-center/?openTemplateCenter=gallery&objType=30)中有大量的模板，支持根据使用场景选择模板，也支持通过关键词搜索模板。​

​

250px|700px|reset

![](https://p1-hera.feishucdn.com/tos-cn-i-jbbdkfciu3/7494b20283454c9198e38eeed145acee~tplv-jbbdkfciu3-image:0:0.image)​​

导入已有 .pptx 格式文件​

你可以将保存在本地或飞书云盘的 .pptx 格式文件转换为飞书幻灯片文件，具体信息请参考[导入 PPT 格式文件](https://www.feishu.cn/hc/zh-CN/articles/716741320420?from=in-ccm-slides)。​

注：支持导入的文件最大为 600 MB。​

步骤二、添加、编辑和整理幻灯片页面​

你可以在幻灯片文件中添加、删除幻灯片页面，调整不同页面间的顺序，或修改画布尺寸。​

添加、删除幻灯片页面​

你可以通过以下任一方式，在创建好的幻灯片文件中快速添加空白幻灯片页面。​

  * 点击左上角的 新建幻灯片。​



  * 右击左侧空白处，选择 新建幻灯片。​



  * 在左侧目录树选中想添加幻灯片的位置，使用快捷键 Ctrl + M 或 Enter。​



右击页面，点击 删除，即可删除对应页面。​

​

使用母版、布局和背景​

添加幻灯片页面时，你还可以点击 + 新建幻灯片 右侧的​ 图标，直接使用特定母版下的布局。母版和布局会预设好幻灯片中不同内容元素的样式、排列方式和页面使用的背景等。你也可以进入母版或布局的编辑页面，按照需要调整其样式。​

具体信息请参考[使用母版和布局](https://www.feishu.cn/hc/zh-CN/articles/590299019774?from=in-ccm-slides)。​

调整幻灯片页面顺序​

在左侧的目录树中，按住幻灯片页面，即可拖拽、移动该页面。​

修改画布尺寸​

点击右上角​ 图标 > 幻灯片设置，修改画布尺寸（即幻灯片页面的大小和比例），以适应不同的演示设备和演示场景。​

画布的默认尺寸为宽屏（16:9），尺寸修改后，画布中的内容对象会按照画布的缩放比例适配缩放，确保对象保留在画布内。​

注：自定义尺寸支持的最小值为 200 px，最大值为 8000 px。如果输入值中有小数，会四舍五入取整。​

步骤三、插入对象与设置格式​

在幻灯片页面中，点击顶部工具栏，你可以添加文本、图形、图片、媒体、图表、表格、智能布局、画板等不同的对象，还可以为不同的对象设置格式。具体信息请参考[设置幻灯片中对象的格式](https://www.feishu.cn/hc/zh-CN/articles/442577259086?from=in-ccm-slides)。​

步骤四、分享与协作​

分享幻灯片文件​

点击幻灯片右上角的 分享，输入想分享的对象，即可将幻灯片文件分享给对方，并赋予其阅读、编辑、管理权限。你也可以点击 复制链接，将链接分享给他人。​

注：幻灯片文件的分享与权限，与文档、表格、多维表格通用，具体信息请参考[快速上手云文档权限](https://www.feishu.cn/hc/zh-CN/articles/360025093793)。​

在幻灯片中评论​

在幻灯片页面上选中任意内容，在浮现的工具栏中点击 评论 图标，或点击顶部工具栏中的 评论，即可针对该内容发表评论。你也可以在选中内容后，按快捷键 Ctrl + Alt + M（Windows）或 Command + Option + M（Mac）来发表评论。​

在未选中任何内容的情况下，点击顶部工具栏中的 评论，即可对整张幻灯片发表评论。​

步骤五、演示幻灯片​

点击页面右上方的 演示，即可从当前页面开始演示内容。​

你也可以点击 演示 旁的​ 图标，选择 演讲者视图 或 从头开始 进行演示。​

选择 从头开始，可从第一页开始演示内容。​

选择 演讲者视图，可从当前页面开始演示内容。在此模式下，系统会同时打开观众视图和演示者视图。在演示者视图中，演讲者可以查看演讲者备注、计时器等信息。​

按 Esc 键可退出演示模式。有关幻灯片演示的具体信息，请参考[演示幻灯片](https://www.feishu.cn/hc/zh-CN/articles/567559924536?from=in-ccm-slides)。​

步骤六、下载幻灯片或转换为模板​

你可以将幻灯片文件下载到本地，也可以将幻灯片文件转换为模板，供后续重复使用或者分享给其他成员使用。​

下载幻灯片文件​

点击右上角​ 图标 > 下载为，可以将幻灯片文件下载为 PDF 文件（.pdf）或本地 PPT 文件（.pptx）文件。​

注：​

  * 支持下载的 .pptx 文件上限为 1 GB；.pdf 文件上限为 128 MB。​



  * 移动端幻灯片文件不支持下载。​



将幻灯片文件转换为模板​

点击右上角​ 图标 > 转换为模板，可以将幻灯片文件保存为自定义模板。​

转换为模板后，可进入[模板中心](https://www.feishu.cn/drive/template-center/?openTemplateCenter=gallery&objType=30)随时查看。​

  * 我的模板：查看自己保存的模板。​



  * 与我共享：查看他人分享给自己的模板。​

步骤七、掌握效率工具​

通过幻灯片中提供的查找/还原历史记录、快捷键以及动态辅助线的功能，你可以快速编辑幻灯片。​

查看和还原幻灯片的历史记录​

在桌面端或网页版，你可以轻松找回幻灯片文件的历史版本，追溯编辑对象；你也可以一键恢复内容至任意历史版本。具体信息请参考[查看和还原幻灯片的历史记录](https://www.feishu.cn/hc/zh-CN/articles/666331696886?from=in-ccm-sheet)。​

使用快捷键​

在创建、编辑和演示幻灯片的过程中，你可以使用键盘快捷键，在幻灯片中进行各种快速操作，如查找替换、复制粘贴、字体加粗、快速演示，提高工作效率。具体信息请参考[使用幻灯片快捷键](https://www.feishu.cn/hc/zh-CN/articles/058251273274?from=in-ccm-sheet)。​

使用动态辅助线​

在幻灯片画布中移动、缩放或旋转元时素，如果出现了中心对齐、对象对齐、对象间距离相等或对象边缘长度相等的情况，系统会自动启动动态辅助线功能，帮助你更精准地调整对象的排版布局。具体信息请参考[幻灯片中的动态辅助线](https://www.feishu.cn/hc/zh-CN/articles/770800296763?from=in-ccm-sheet)。​

步骤八、在移动端使用幻灯片​

你可以在移动端查看、评论幻灯片。​

  * 查看幻灯片：打开幻灯片后，你可以上下滑动屏幕查看内容，也可以双指缩放放大或缩小画面。​



  * 评论幻灯片页面：点击幻灯片页面后，页面底部会出现评论按钮。直接点击该按钮即可为页面添加评论。​



  * 评论幻灯片页面中的某个对象：点击幻灯片页面后，再次点击页面中的某个对象，如文本框，页面底部会出现评论按钮。直接点击该按钮即可为选中的对象添加评论。​



  * 查看评论：如果幻灯片页面或者页面中的对象有评论，页面右上角会出现黄色的评论气泡，点击气泡即可打开相关评论，上下滑动可以切换至上一条或下一条评论。​
