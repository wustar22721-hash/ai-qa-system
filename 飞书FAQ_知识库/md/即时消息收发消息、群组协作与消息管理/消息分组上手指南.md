一、功能简介​

​

🔖

版本要求：飞书 V5.14 及以上版本​

​

使用消息分组功能可以对众多消息进行分类，例如单聊消息、群聊消息、@ 你的消息、未读消息、免打扰消息等。在飞书桌面端，消息分组默认展示在消息列表的左侧，你可以自由调整消息分组占据的页面宽度，设置仅展示分组图标或完全隐藏消息分组，也可以移除或添加部分分组。​

二、操作流程​

展示或隐藏分组​

在桌面端，消息分组默认展示在消息列表的左侧，可通过以下几种方式展示或隐藏分组。​

  * 将鼠标悬停在消息分组和消息列表中间，出现蓝色竖线后，拖拽鼠标可以调节消息分组区域的宽度。将蓝色竖线拖至最左侧可以隐藏分组。​



  * 在消息分组区域的左上角，点击 隐藏/展示分组 图标，即可快速隐藏或展示分组。在展示分组的状态下，将鼠标悬停在 隐藏/展示分组 图标上，可按需选择 隐藏分组 或 仅展示图标。​



  * 使用 Command \+ G（Mac）或 Ctrl + G（Windows）快捷键隐藏分组。再次按下此快捷键可以重新展示分组。​

切换及编辑分组​

使用桌面端时，可参考下方说明切换或编辑分组。​

  * 通过 Command \+ 上下键（Mac）或 Ctrl + 上下键（Windows）切换不同分组。在分组中，通过鼠标点击或上下键选择待处理的会话。​



  * 点击 ​ 编辑分组 图标，在 编辑分组 弹窗中按需修改配置，完成后在弹窗右下角点击 保存。​



  * 通过拖拽调整分组排序。​



  * 在分组名称的左侧，点击绿色​ 图标添加需要展示的分组，点击红色的 — 图标移除已添加的分组。不支持移除名称为“消息”的分组。​



  * 在分组名称的右侧，点击​ 或​ 图标配置是否将该分组中的会话展示在“消息”分组中。​



注：每个分组的配置选项有所不同，须以实际界面为准。​
